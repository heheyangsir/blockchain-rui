# 部署计数器智能合约
编写一个简单的计数器智能合约，并使用 Hardhat 部署到本地网络。
npx hardhat node //启动本地网络
```bash
npx hardhat compile //编译智能合约
npx hardhat test test/Counter.test.ts //运行单元测试
npx hardhat ignition deploy ./ignition/modules/Counter.ts --network localhost //部署合约到指定网络
npx hardhat ignition deploy ./ignition/modules/Counter.ts --network localhost//部署合约到指定网络
```
